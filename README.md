# Historias de Vo

Project foundation for a local MVP with two independent TypeScript applications:

- `frontend/`: Next.js web application
- `backend/`: NestJS API

## Node.js

This repository targets Node.js `24.x` (latest LTS line per project requirements).

## Local setup

Install dependencies separately in each project:

```bash
cd frontend && npm install
cd ../backend && npm install
```

## Frontend commands

```bash
cd frontend
npm run dev
npm run test
npm run build
npm run lint
```

## Backend commands

```bash
cd backend
npm run dev
npm run test
npm run build
npm run lint
```
